# Checkpoints

Acest folder pastreaza doar cateva modele reprezentative pentru demo si prezentare.
Rularile noi de antrenare pot genera multe checkpoint-uri, iar `.gitignore` le exclude
implicit ca sa nu incarce repository-ul.

Modele utile pentru demo:

- `cnn_contact_threshold/basecnn_contact_threshold_gamma06_lr8e4_lines28/block_blast_basecnn_contact_threshold_gamma06_v1.zip` - model 8x8 folosit implicit de `watch.py`.
- `4x4_best8x8/4x4_best8x8_basecnn_g03_lr2e3/block_blast_4x4_best8x8_basecnn_v1.zip` - model 4x4 pentru comparatia de viteza/dificultate.

Unele checkpoint-uri istorice sunt pastrate pentru documentare, dar nu toate sunt
compatibile cu interfata curenta.
